# 내 앱을 Workflow Auto 에 붙이기 (복붙용 프롬프트)

개발을 몰라도 됩니다. 아래 글상자를 통째로 복사해서
**Claude / Codex / Cline** 같은 AI 코딩 도구에 붙여넣으면, 알아서 만들어 줍니다.

기억할 것은 딱 하나입니다.

> **내 앱은 고치지 않습니다.** 옆에 "어댑터"라는 작은 파일 하나를 새로 만들어
> 같이 켜 두는 것뿐입니다. 어댑터가 통역사 역할을 해서, Workflow Auto 가
> 내 앱을 부를 수 있게 됩니다.

---

## 1단계 - 내 앱이 어느 쪽인지 고르기

| 내 앱 모양 | 쓸 프롬프트 |
|---|---|
| 브라우저로 접속하는 웹앱 / 서버 주소가 있는 앱 | **A. 웹앱용** |
| PC에 설치해서 쓰는 프로그램, 실행파일, 파이썬 스크립트 | **B. PC 설치형용** |

애매하면 A 로 시작하세요. AI 도구가 알아서 되물어 봅니다.

---

## 2단계 - 아래를 복사해서 AI 도구에 붙여넣기

### A. 웹앱 / HTTP API 가 있는 앱

```
내 앱을 "MCP 서버"로 감싸는 어댑터를 만들어 줘.

[규칙]
- 내 앱 코드는 절대 수정하지 마. 새 폴더(mcp_adapter/)에 파일만 새로 만들어.
- 파이썬으로 만들고, mcp 라이브러리의 FastMCP 를 써.
- 전송 방식은 streamable-http 여야 해. mcp.run(transport="streamable-http")
- 파일 맨 위에 `from __future__ import annotations` 를 절대 넣지 마.
  (넣으면 MCP 가 함수의 인자 타입을 못 읽어서 고장나.)
- 내 앱 주소는 코드에 박지 말고 환경변수 APP_BASE_URL 로 받아.
- 내 앱의 기능 하나당 파이썬 함수 하나를 만들고, 그 함수 위에 @mcp.tool() 을 붙여.
- 함수의 인자마다 타입을 적어. (str, int, list[str] 처럼)
- 함수 docstring 첫 줄에 "이 기능이 무엇을 하는지"를 한국어로 한 문장 적어.
  오케스트레이터가 그 문장만 보고 언제 이 기능을 쓸지 판단하니까 구체적으로 써.
  그리고 Args: 아래에 인자마다 한국어 설명을 적어.
- 비밀번호나 토큰은 코드에 쓰지 말고 환경변수로 읽어.
- 다 만들면 requirements.txt 와, 실행 방법 3줄짜리 README 도 같이 만들어.

[내 앱 정보]
- 앱 이름: (여기에 적으세요)
- 앱이 하는 일 한 줄 설명: (여기에 적으세요)
- 앱 주소: (예: http://localhost:8100)
- 이 앱의 기능들: (아는 만큼만 적으세요. 예: "사번으로 직원 조회", "주간보고 양식 채우기")
- API 문서나 코드: (있으면 아래에 붙여넣으세요. 없으면 "없음"이라고 쓰고,
  앱 소스 폴더를 열어서 AI 에게 직접 읽어 보라고 하세요.)

[참고]
이 저장소의 templates/mcp_adapter_http/server.py 가 견본이야. 그걸 복사해서
TODO 부분만 내 앱에 맞게 채우는 방식으로 만들어 줘.
example_app/ 폴더에 실제로 그렇게 만든 완성 예시가 있으니 같이 참고해.
```

### B. PC에 설치해서 쓰는 앱 (실행파일 / 스크립트)

```
내 앱을 "MCP 서버"로 감싸는 어댑터를 만들어 줘.

[규칙]
- 내 앱 코드는 절대 수정하지 마. 새 폴더(mcp_adapter/)에 파일만 새로 만들어.
- 파이썬으로 만들고, mcp 라이브러리의 FastMCP 를 써.
- 전송 방식은 streamable-http 여야 해. mcp.run(transport="streamable-http")
- 파일 맨 위에 `from __future__ import annotations` 를 절대 넣지 마.
- 내 앱을 subprocess 로 실행해서 결과를 돌려주는 방식으로 만들어.
- 보안상 shell=True 는 절대 쓰지 마. 명령어는 리스트로 넘겨.
- 사용자가 입력한 값은 옵션 "값"으로만 넘기고, 옵션 이름까지 사용자가
  정하게 두지 마.
- 실행파일 경로는 코드에 박지 말고 환경변수 APP_COMMAND 로 받아.
- 기능 하나당 함수 하나, 위에 @mcp.tool(), 인자마다 타입,
  docstring 첫 줄에 한국어로 무엇을 하는지, Args: 에 인자 설명.
- 타임아웃을 걸어서 앱이 멈춰도 어댑터는 안 멈추게 해.
- 다 만들면 requirements.txt 와 실행 방법 3줄짜리 README 도 같이 만들어.

[내 앱 정보]
- 앱 이름: (여기에 적으세요)
- 앱이 하는 일 한 줄 설명: (여기에 적으세요)
- 실행파일 경로: (예: C:\Program Files\MyApp\myapp.exe 또는 python main.py)
- 실행 예시: (평소 터미널에 치는 명령어를 그대로 적으세요)
- 이 앱의 기능들: (아는 만큼만)

[참고]
이 저장소의 templates/mcp_adapter_cli/server.py 가 견본이야. 그걸 복사해서
TODO 부분만 내 앱에 맞게 채우는 방식으로 만들어 줘.
```

---

## 3단계 - 켜 보기

AI 가 만들어 준 폴더에서:

```bash
pip install -r requirements.txt
python server.py
```

`http://localhost:9001/mcp` 같은 주소가 뜨면 성공입니다.

> PC 설치형 앱이면, 그 앱이 깔린 PC에서 어댑터를 켜 두어야 합니다.

## 4단계 - 앱스토어에 등록

Workflow Auto 화면 → **앱스토어** → *내 앱 등록하기* 에 3단계에서 나온 주소를 넣습니다.
등록하면 기능 목록을 자동으로 읽어 옵니다.

처음에는 **개인용**으로 저장되어 나만 씁니다. 잘 돌아가면 *공식 등록 신청* 을
누르세요. 관리자가 승인하면 모두가 쓸 수 있는 **공식 앱**이 됩니다.

## 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 등록은 됐는데 `unreachable` 이라고 뜬다 | 어댑터가 켜져 있는지, 주소가 `/mcp` 로 끝나는지 |
| 기능이 0개로 나온다 | 함수 위에 `@mcp.tool()` 이 붙어 있는지 |
| 인자 관련 에러가 난다 | 파일 맨 위의 `from __future__ import annotations` 를 지웠는지 |
| 오케스트레이터가 내 앱을 안 부른다 | docstring 첫 줄 설명이 너무 막연한지 (구체적으로 다시 쓰기) |

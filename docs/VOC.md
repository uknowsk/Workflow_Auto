# 앱 의견(VOC)과 앱 업데이트

앱스토어에 앱이 쌓이면 "그 앱 이거 안 되던데요"가 복도에서만 오갑니다.
그 말이 앱을 올린 사람에게 닿지 않으면 앱은 고쳐지지 않고, 사람들은 그 앱을
조용히 안 쓰게 됩니다. 이 기능은 그 말을 앱 옆에 붙여 두고 등록자에게
알림으로 보내는 것, 그리고 등록자가 고친 앱을 다시 올릴 수 있게 하는 것입니다.

## 쓰는 사람 입장

1. 앱스토어에서 앱 카드의 **💬 의견** 을 누릅니다.
2. 종류(잘 안 돼요 / 이런 게 있으면 / 사용법 문의)를 고르고 한 줄 요약을 씁니다.
   별점은 안 매겨도 됩니다. 별점만 받으면 등록자가 무엇을 고쳐야 할지 모릅니다.
3. 보내면 **앱을 올린 사람에게 알림**이 갑니다.
4. 등록자가 답하면 **다시 나에게 알림**이 옵니다. 내가 보낸 의견은
   «의견함 → 내가 보낸 의견» 에 모입니다.

이미 올라온 의견은 그 앱을 볼 수 있는 사람이면 누구나 봅니다. 같은 제보가
여러 번 올라오는 걸 줄이고, "이건 이미 고치는 중"이라는 답변이 모두에게
보이게 하려는 것입니다.

## 앱을 올린 사람 입장

- **의견함** 에 내 앱에 온 의견이 모입니다. 각 의견을 접수 → 확인 중 →
  처리 완료(또는 안 고침)로 옮기고 답변을 답니다.
- 남이 쓴 의견을 **지울 수는 없습니다**. 답만 답니다. 등록자가 마음에 안 드는
  제보를 지울 수 있으면 의견함이 의미가 없기 때문입니다. 잘못 올린 의견은
  쓴 사람이 지웁니다.
- 고쳤으면 앱 카드의 **⬆ 업데이트** 로 새 버전을 올립니다.

## 업데이트 규칙

업데이트는 **바로 반영**됩니다. 올릴 때마다 관리자 승인을 다시 받게 하면
개발자가 업데이트를 안 하게 되고, 그러면 고쳐진 앱이 사람들에게 가지 않습니다.
대신 세 가지를 둡니다.

1. **이력이 남습니다** — 누가 언제 무엇을 바꿨는지 (`app_versions` 표)
2. **알림이 갑니다** — 이 앱을 카드에 담아 쓰는 사람들에게, 그리고 공식
   (approved) 앱이면 관리자에게도
3. **되돌릴 수 있습니다** — 업데이트 상자의 이력에서 «이걸로 되돌리기»

앱을 어떻게 등록했느냐에 따라 올리는 방법이 다릅니다.

| 등록 방식 | 업데이트 | 되돌리기 |
| --- | --- | --- |
| 주소만 등록(manual) | 주소·버전 표기를 바꿉니다 | 옛 주소로 되돌립니다 |
| GitHub | 최신 코드를 다시 받아옵니다 | 옛 버전 폴더를 다시 가리킵니다 |
| ZIP | 새 ZIP 을 올립니다 | 옛 버전 폴더를 다시 가리킵니다 |

GitHub·ZIP 으로 올린 소스는 **버전마다 폴더를 따로** 둡니다.

```
data/packages/<앱 slug>/20260920-071500/   <- 이때 올린 버전
data/packages/<앱 slug>/20260921-103000/   <- 지금 쓰는 버전
```

앱의 `package_path` 가 그중 지금 쓰는 폴더를 가리키고, 되돌리기는 그 값을
옛 폴더로 바꾸는 일입니다. 폴더는 최근 5개까지만 남기고 오래된 것은
지웁니다(디스크가 무한하지 않으므로). 이력에 남아 있는 폴더는 지우지 않습니다.

## API

| 하는 일 | 주소 |
| --- | --- |
| 의견 남기기 | `POST /api/apps/{app_id}/voc` |
| 이 앱에 온 의견 | `GET /api/apps/{app_id}/voc` |
| 내 앱에 온 의견 | `GET /api/voc/inbox?open_only=true` |
| 내가 보낸 의견 | `GET /api/voc/sent` |
| 앱별 의견 수 | `GET /api/voc/counts` |
| 답변·상태 바꾸기 | `PATCH /api/voc/{voc_id}` |
| 내가 쓴 의견 지우기 | `DELETE /api/voc/{voc_id}` |
| 버전 이력 | `GET /api/apps/{app_id}/versions` |
| 새 버전(주소) | `POST /api/apps/{app_id}/update/endpoint` |
| 새 버전(GitHub) | `POST /api/apps/{app_id}/update/from-github` |
| 새 버전(ZIP) | `POST /api/apps/{app_id}/update/from-zip` |
| 되돌리기 | `POST /api/apps/{app_id}/versions/{version_id}/rollback` |

## 나중에 손볼 자리

- 알림은 지금 화면 안에서만 보입니다. 회사 메일이나 사내 메신저로도 보내고
  싶어지면 `backend/app/notify.py` 의 `send()` 안에서 한 줄 더 부르면 되고,
  부르는 쪽 코드는 손댈 필요가 없습니다.
- 의견이 많아지면 "이 앱 의견 10건 중 8건이 처리 완료" 같은 값을
  이달의 앱 점수에 넣을 수 있습니다(`GET /api/voc/counts` 가 이미 셉니다).
